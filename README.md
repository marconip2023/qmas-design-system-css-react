# qmas-design-system-css-react

Managed store for the QMAS **Design System — CSS/React edition** skill. This is the
CSS/React translation of `qmas-design-system` (the Figma-plugin skill): drop-in CSS
custom-property tokens, Ant Design v6 component rules, type scale, table/filter
shadow rule, App Shell, and the pre-output checklist — for building QMAS UI in
Claude design / HTML / React output that does **not** go into Figma.

- **Latest (stable):** [qmas-design-system-css-react-latest.skill](https://github.com/marconip2023/qmas-design-system-css-react/raw/main/qmas-design-system-css-react-latest.skill)
- **v1:** [qmas-design-system-css-react-v1.skill](https://github.com/marconip2023/qmas-design-system-css-react/raw/main/qmas-design-system-css-react-v1.skill)

A `.skill` file is just a zip. Install via Claude → Settings → Capabilities → Skills → Upload skill.
